# HR Analytics – End-to-End Data Analytics Project

## Project Overview

This project demonstrates an end-to-end HR Analytics workflow using Python (Pandas), SQL, and Microsoft Power BI.

The objective is to analyze employee attrition, understand workforce trends, explore employee satisfaction, and provide recommendations that support HR decision-making.

## Tools and Technologies

- **Python:** Pandas, Jupyter Notebook
- **SQL:** Data querying and analysis
- **Power BI:** Interactive dashboards and DAX
- **GitHub:** Project documentation and version control

## Project Workflow

### 1. Data Cleaning Using Python and Pandas

The project includes a Jupyter Notebook named `HR_Attrition_Analysis.ipynb` and original and cleaned HR datasets.

The notebook documents the data preparation process used for HR analysis.

### 2. Data Analysis Using SQL

SQL scripts are included to document the HR data analysis stage.

### 3. Data Visualization Using Power BI

Created an interactive three-page HR Analytics report.

**Page 1 – HR Overview**
- Employee KPI cards
- Department-wise attrition
- Gender-wise attrition
- Overtime vs attrition
- Attrition by age group
- Job satisfaction vs attrition
- Attrition by job role

**Page 2 – Employee Insights**
- Education field vs attrition
- Business travel vs attrition
- Average monthly salary by department
- Environment satisfaction vs attrition
- Marital status vs attrition
- Work-life balance vs attrition

**Page 3 – HR Key Insights & Recommendations**
- Key workforce findings
- HR recommendations
- Business conclusion

## Key Finding

The overall employee attrition rate is 20.60%, indicating an opportunity to investigate retention factors such as overtime, satisfaction, work-life balance, and compensation.

## Business Recommendations

- Investigate reasons for employee departures.
- Review workload and overtime practices.
- Monitor employee satisfaction.
- Evaluate compensation competitiveness.
- Strengthen employee career development opportunities.

## Conclusion

This project demonstrates how Python, SQL, and Power BI can be used together to prepare HR data, analyze workforce patterns, and communicate findings through interactive dashboards.
